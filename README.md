# Fruit Image Classification

A deep learning project that classifies fruit images into three categories: **Apple, Cucumber, and Pear**.

## Dataset

* Apple: 8,290 images
* Cucumber: 8,290 images
* Pear: 8,290 images
* Total: 24,870 images

## Model

The project uses **MobileNetV2 Transfer Learning** for image classification.

## Technologies

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Classes

1. Apple
2. Cucumber
3. Pear

## Project Workflow

Dataset → Preprocessing → MobileNetV2 → Training → Fine-Tuning → Evaluation → Prediction

## Final Model

The trained model is saved as:

`fruit_classifier_final.keras`
